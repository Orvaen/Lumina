## Un programme complet

```c
#include <Lumina/lumina.h>

int main(void)
{
    if (!lumInit())
        return -1;

    LUMwindow* window = lumCreateWindowEx(&(LUMwindowdesc)
    {
        .width       = 640,
        .height      = 480,
        .title       = "Bonjour Lumina",
        .makeCurrent = LUM_ON
    });

    if (!window)
    {
        lumTerminate();
        return -1;
    }

    while (!lumWindowShouldClose(window))
    {
        glClear(GL_COLOR_BUFFER_BIT);

        lumSwapBuffers(window);
        lumPollEvents();
    }

    lumTerminate();
    return 0;
}
```

<Aside title="Lumina est un fork de GLFW">
  Lumina reprend [GLFW](https://www.glfw.org/) 3.4 là où son développement
  amont s'est arrêté. L'API est la même, seuls les noms changent :
  `glfwCreateWindow` est devenu `lumCreateWindow`, `GLFWwindow` est devenu
  `LUMwindow`, `GLFW_KEY_ESCAPE` est devenu `LUM_KEY_ESCAPE`. Ces pages sont
  générées depuis les en-têtes et les guides de Lumina, elles décrivent donc
  toujours le code de ce dépôt.
</Aside>
