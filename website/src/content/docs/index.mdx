## A complete program

```c
#include <Lumina/lumina.h>

int main(void)
{
    if (!lumInit())
        return -1;

    LUMwindow* window = lumCreateWindowEx(&(LUMwindowdesc)
    {
        .width       = 640,
        .height      = 480,
        .title       = "Hello Lumina",
        .makeCurrent = LUM_ON
    });

    if (!window)
    {
        lumTerminate();
        return -1;
    }

    while (!lumWindowShouldClose(window))
    {
        glClear(GL_COLOR_BUFFER_BIT);

        lumSwapBuffers(window);
        lumPollEvents();
    }

    lumTerminate();
    return 0;
}
```

<Aside title="Lumina is a fork of GLFW">
  Lumina continues [GLFW](https://www.glfw.org/) 3.4 after upstream development
  stopped. The API is the same; only the names changed — `glfwCreateWindow`
  became `lumCreateWindow`, `GLFWwindow` became `LUMwindow`, `GLFW_KEY_ESCAPE`
  became `LUM_KEY_ESCAPE`. These pages are generated from Lumina's own headers
  and guides, so they always describe the code in this repository.
</Aside>
